# SCP-0002: The three values of SPEC-PRJ-003 written "target value, to confirm"

```yaml
statut: proposee
demandeur: coordinator
exigences_touchees:
  - "modified: SPEC-PRJ-003 (coverage: the save interval, the maximum unit size, the response bound; test TST-PRJ-003c added; status unchanged)"
decide_by: null
```

## Intent

SPEC-PRJ-003 states its nominal and limit cases with three values written "target value, to confirm": the interval within which a change is saved, the maximum size of a unit that stays editable, and the response bound within which it stays editable. ENG-0003 delivered the editor with one of them chosen by the implementation (a save runs 600 ms after the last change) and the other two neither fixed nor tested. A requirement with an unconfirmed value cannot be verified in full; the operator confirms the values, and a test then measures them.

## Scope and non-goals

Touches the coverage of SPEC-PRJ-003 in `dossier-recette/11_PROJECT_STRUCTURE.md` and adds one test to its table. Does not change the requirement sentence, nor the save behaviour delivered by ENG-0003 (saved, unsaved, conflict; a refused save kept on screen with Retry).

## Proposed modification

Coverage, nominal: "a change is saved within 600 ms of quiet after the last change, and the state shows saved" (the value ENG-0003 implements; its only cost is one write per pause in typing).

Coverage, limit, option A (recommended): "a unit of 100 000 characters stays editable with a keystroke rendered within 100 ms, measured by TST-PRJ-003c on the machine that runs the tests"; option B: leave both values open until a long-form user asks, and say so in the coverage.

| Test | Artefact | Nature | Expected result |
|---|---|---|---|
| TST-PRJ-003c | planned | performance | A unit of the maximum size stays editable within the response bound; the measurement is recorded with the run. |

## Example

An author pastes a 100 000 character chapter into a unit: the editor keeps answering each keystroke within the bound, and every pause of 600 ms saves the text, the indicator showing saved.

## Recommendation

Option A. The two figures are starting points to measure, not promises: the test records the measurement, and a later SCP raises or lowers them from the evidence.
