# Milestones

Each milestone is a set of requirements of the requirements folder. A milestone is reached when all its requirements are IMPLEMENTED on the traceability matrix and the commitments that contribute to it are held. This file carries no dates; deadlines live in commitments. The order of the table is the intended order of work; dependencies are declared in commitments. Requirements are written for a milestone when it approaches the frontier, so only the milestones at or near the frontier name requirements at this version.
