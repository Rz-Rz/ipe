# ADR-0003: decision of DA-0003

- Context: Which technical stack carries IPE's first release?
- Decision: A. A TypeScript kernel with no Node and no DOM dependency; storage, clock and random sources as adapters, implemented on Node for the desktop; a React and Vite interface running in a browser window and reaching the core through one message channel; an Electron shell for the desktop surface; Playwright for end-to-end tests as a user.
- Reason: the only option whose prerequisites are all present on the build machine without administrator rights; one build for both surfaces; aligned with the company's interface stack and the engine's language; testable as a user here. The default applied in the operator's absence, as DA-0003 states.
- Date: 2026-10-15
- Consequences: the repository is a pnpm workspace with `packages/kernel` (pure), `packages/adapters-node`, `apps/desktop` (Electron shell and React interface); the Markdown editor is CodeMirror 6, whose Vim extension answers N20; project data on disk is Markdown for manuscript units and a documented JSON object store under `.ipe/` inside the project folder; the interface imports no Node module.
- Reversibility: by an SCP referencing this ADR (anti-oscillation guard).
