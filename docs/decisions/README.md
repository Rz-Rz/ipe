# Decision records

Decision requests (DA) and decision records (ADR) written before the steering kit was installed in this repository.

- The numbers DA-0001, DA-0002, ADR-0001, and ADR-0002 were not reserved through `agelaios numero`, because the kit was not installed when they were written. After installation, reserve the numbers, renumber if the authority hands out different ones, and move the files into `.agelaios/orchestration/DA/` and `.agelaios/orchestration/ADR/`.
- Both requests are decided. The decider is the operator; the decisions were taken in session on 2026-10-15. The baseline (`docs/IPE_PRODUCT_BASELINE.md`, Section 7) records them.
- A decision is reversed only by an SCP that references its ADR.
